# UI 라이브러리 예제

HandStack 화면(Tabler 기반 UI)에서 자주 쓰는 레이아웃·컴포넌트 마크업을 분류별로 모은 개발자 참고 예제입니다.
각 예제는 `<id>.html` 브라우저 미리보기 페이지로 제공됩니다.

마크업은 Tabler(`tabler-core`) 컴포넌트 클래스와 master-css(`f:`, `b:`, `m-`, `p-` 등 속성형 유틸리티) 표기를 함께 사용합니다.
미리보기를 확인하려면 `wwwroot` 호스트(또는 `ack --modules=wwwroot,...`)를 기동한 뒤 `/sample/ui-library/<id>.html` 경로로 접속하세요.
