참고사항

작업일자통제

  • 이월: 현재 기수의 회계기간 말일 자로 마감일이 자동 입력되어 통제합니다.
  • 취소: 이전 기수 회계기간 말일 자로 마감일이 자동 입력되어 통제합니다.
  • 일마감, 월마감 등으로 관리하는 경우 마감일을 직접 입력하여 통제합니다.
