syn.config.json 편집 도구

SystemID ack 프로그램에서 운영하는 시스템 식별 ID를 입력합니다. (기본값: HANDSTACK)
ApplicationID 애플리케이션을 식별하는 고유 ID를 입력합니다.
ProjectID 프로젝트를 식별하는 고유 ID를 입력합니다.
SystemVersion 클라이언트 시스템 버전을 주.부.수 숫자로 관리합니다.
TransactionTimeout 거래 요청에 대한 응답을 기다리는 제한 시간을 밀리초 단위로 입력합니다. (기본값: 180000)
HostName 클라이언트를 구동하는 호스트 애플리케이션의 이름을 입력합니다. (기본값: WebClient)
UIEventLogLevel 클라이언트 UI 이벤트 로그를 기록할 최소 수준을 설정합니다. (기본값: Verbose)
IsLocaleTranslations 다국어 번역 리소스 사용 여부를 설정합니다. (기본값: false)
LocaleAssetUrl 다국어 리소스 파일을 불러오는 기본 경로입니다. (기본값: /assets/shared/language/)
AssetsCachingID 정적 리소스 캐싱을 구분하기 위한 식별 ID를 입력합니다.
IsClientCaching 클라이언트 정적 리소스 캐싱 사용 여부를 설정합니다. (기본값: true)
IsDebugMode 클라이언트 디버그 모드 사용 여부를 설정합니다. (기본값: false)
IsBundleLoad 번들 파일(syn.bundle.js)로 스크립트를 불러올 지 여부를 설정합니다. (기본값: false)
IsReportifyModule Reportify 연동 모듈 여부를 설정합니다. (기본값: false)
ContractRequestPath UI 화면 요청 기본 경로입니다. 개발 목적이 아닌경우 기본값을 적용 해야 합니다. (기본값: view)
TenantAppRequestPath 테넌트 애플리케이션 요청 기본 경로입니다. (기본값: app)
SharedAssetUrl 공용 정적 리소스를 불러오는 기본 경로입니다. (기본값: /assets/shared/)
IsApiFindServer DiscoveryApiServerUrl을 통해 API 서버 정보를 찾을지 여부를 설정합니다. (기본값: false)
DiscoveryApiServerUrl API 서버 정보를 검색하기 위한 디스커버리 서버 Url을 입력합니다.
ReportServer 리포트를 조회하는 서버 Url을 입력합니다.
FileManagerServer 파일을 업로드/다운로드 하는 파일 관리 서버 Url을 입력합니다. (기본값: http://localhost:8421)
FindClientIPServer 클라이언트 IP를 확인하는 서버 경로를 입력합니다. (기본값: /checkip)
FindGlobalIDServer GlobalID를 발급 받는 서버 Url을 입력합니다.
FileServerType 파일 저장소 유형을 설정합니다. L: 로컬 파일 시스템, R: 원격 파일 서버 (기본값: L)
FileBusinessIDSource 파일 업무 ID의 출처를 설정합니다. (기본값: None)
CookiePrefixName 클라이언트에서 사용하는 쿠키 이름의 접두사를 입력합니다. (기본값: HandStack)
Environment 클라이언트가 구동되는 실행 환경을 설정합니다. (기본값: Development)
DomainAPIServer
ServerID 업무 API 서버를 식별하는 고유 ID를 입력합니다. (기본값: SERVERD01)
ServerType 업무 API 서버 유형을 입력합니다. (기본값: D)
Protocol 업무 API 서버 접속 프로토콜을 입력합니다. (기본값: http)
IP 업무 API 서버의 IP 또는 호스트 이름을 입력합니다. (기본값: localhost)
Port 업무 API 서버의 포트 번호를 입력합니다. (기본값: 8421)
Path 거래를 실행하는 API 경로를 입력합니다. (기본값: /transact/api/transaction/execute)
ClientIP 클라이언트 IP 또는 호스트 이름을 입력합니다. (기본값: localhost)
Program
ProgramName 클라이언트 프로그램 이름을 입력합니다.
ProgramVersion 클라이언트 프로그램 버전을 주.부.수 숫자로 관리합니다. (기본값: 1.0.0)
LanguageID 클라이언트 표시 언어 코드를 입력합니다. (기본값: ko)
LocaleID 클라이언트 로케일 코드를 입력합니다. (기본값: ko-KR)
BranchCode 업무를 처리하는 지점 코드를 입력합니다.
Transaction
ProtocolVersion 거래 프로토콜 버전을 입력합니다. (기본값: 001)
SimulationType 거래 처리 시뮬레이션 유형을 설정합니다. (기본값: P)
DataFormat 거래 데이터 포맷을 설정합니다. (기본값: J)
MachineTypeID 거래를 요청하는 클라이언트 기종 ID를 입력합니다. (기본값: WEB)
EncryptionType 거래 데이터 암호화 범위를 설정합니다. (기본값: P)
EncryptionKey 거래 데이터 암호화 키의 출처를 설정합니다. (기본값: G)
CompressionYN 거래 데이터 압축 사용 여부를 설정합니다. (기본값: N)
EnvironmentSetting
Application.LoaderPath 애플리케이션을 구동하는 로더 스크립트 경로를 입력합니다. (기본값: /js/syn.domain.js)
Application.CodeHelpID 애플리케이션에서 사용하는 공통 코드 도움 창의 거래 ID를 입력합니다. (예: IQA|SYS010|LD01)
Definition.BindingAction 하위 정의의 Styles, Scripts, Controls를 상위 정의에 추가할지 대체할지 설정합니다. (기본값: Append)
Definition.Styles 모듈에서 추가로 불러올 CSS 파일 경로를 쉼표(,)로 구분해서 입력합니다. (예: /wwwroot/css/module.css)
Definition.Scripts 모듈에서 추가로 불러올 JS 파일 경로를 쉼표(,)로 구분해서 입력합니다.
Definition.Controls 모듈에서 추가로 등록할 사용자 컨트롤 이름을 쉼표(,)로 구분해서 입력합니다.
ModuleID 모듈을 식별하는 고유 ID 입니다. (예: wwwroot)
IsProxyServe 리버스 프록시 경로로 서비스되는지 여부를 설정합니다. (기본값: false)
ProxyPathName 리버스 프록시로 서비스될 때 사용하는 기본 경로 이름을 입력합니다. (IsProxyServe가 true인 경우 사용)
