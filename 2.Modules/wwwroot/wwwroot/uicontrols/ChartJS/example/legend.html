Legend

chartjs.org 공식 샘플(docs/samples/legend/*) 5종을 <syn_chartjs>로 재현합니다.

Events

범례 항목에 마우스를 올리면 onHover/onLeave 로 다른 선을 흐리게 처리합니다.

HTML Legend

Chart.js 기본 범례 대신 <ul> DOM으로 범례를 그리고 클릭 시 데이터셋을 토글합니다.

Point Style

legend.labels.usePointStyle: true 로 범례 마커를 포인트 모양과 맞춥니다.

Position

legend.position 4가지(top/bottom/left/right)를 비교합니다.

top

bottom

left

right

Title

legend.title.display/text 로 범례 상단에 소제목을 붙입니다.
