Line Charts

chartjs.org 공식 샘플(docs/samples/line/*) 7종을 <syn_chartjs>로 재현합니다.

Line

기본 라인 차트, tension 으로 곡선을 만듭니다.

Line Styling

borderDash , borderWidth , fill 로 선 스타일을 바꿉니다.

Point Styling

데이터셋마다 다른 pointStyle (circle/triangle/rect/star)을 지정합니다.

Segments

segment 콜백으로 값이 감소하는 구간만 빨간 점선으로 표시합니다.

Stepped Line

stepped: 'before'/'middle'/'after' 로 계단식 선을 그립니다.

Cubic Interpolation Mode

cubicInterpolationMode: 'default' 와 'monotone' 을 비교합니다.

Multi Axis

두 개의 Y축(왼쪽/오른쪽)에 서로 다른 척도의 데이터셋을 연결합니다.
