CodePicker 전체 기능 확인

코드/이름 입력창 구성(codeElementClass, codeElementWidth, textElementWidth), required/readonly/disabled, isMultiSelect, 조회 조건(parameters, toParameterString/toParameterObject), getValue/setValue/setText/clear/open/find, change/buttonClick 핸들러를 확인합니다.

돋보기 버튼의 검색 팝업은 서버에 dataSourceID(예: CHP_PRODUCT)가 등록된 환경에서 동작합니다. 서버가 없는 환경에서는 아래 "예제용 값 선택" 버튼으로 팝업 선택 결과를 흉내 내어 값 조회/설정 API 와 이벤트를 확인할 수 있습니다.

1. 입력창 구성

옵션 조합컨트롤
코드 + 이름 입력창 모두 표시 (기본)
이름만 표시 (codeElementClass: 'hidden')
입력창 너비 지정 (codeElementWidth: '100px', textElementWidth: '240px')
필수 입력 (required: true)
읽기 전용 (readonly: true, 팝업은 열 수 있음)
비활성 (disabled: true)
다중 선택 (isMultiSelect: true) - 코드/이름이 콤마로 연결됨
