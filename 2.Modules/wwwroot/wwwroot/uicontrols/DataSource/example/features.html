DataSource 전체 기능 확인

storeType(Form/Grid), columns(dataType 별 기본값), bindingSourceAsync 로 연결하는 양방향 바인딩(TextBox/DropDownList/CheckBox/TextArea), getValue(isAll)/setValue/clear/getMetaStore, 그리드 저장소의 Flag(R/C/U/D) 를 확인합니다. 입력 컨트롤을 수정하면 오른쪽 저장소 내용이 바뀌고, 버튼으로 저장소를 바꾸면 화면 컨트롤에 반영됩니다.

참고: 현재 입력 컨트롤들은 bindingID 옵션만으로 자동 연결되지 않습니다. 이 예제는 pageLoad 에서 syn.uicontrols.$data.bindingSourceAsync(컨트롤ID, dataSourceID) 를 호출해 연결합니다.
