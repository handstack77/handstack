HandStack $mediaplayer 예제

Video.js 재생 기능과 HandStack 객체 행·재생 이력 Row/List 계약을 기능별로 확인합니다.

  • 기본 재생 제어 단일 객체, video/audio, 상태 및 제어 메서드
  • 재생목록·이력 바인딩 객체 배열, 자동 이동, 이벤트, Row/List 결과
  • YouTube·스트리밍 videojs-youtube, HLS, MPEG-DASH 혼합 목록
  • 자막·테마·플러그인 VTT 자막, runtime 테마, Video.js plugin escape hatch
