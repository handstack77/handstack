DatePicker 전체 기능 확인

초기값 축약 표기(value), format, minDate/maxDate, defaultDate/setDefaultDate, firstDay/showWeekNumber/numberOfMonths/yearSuffix, 이전/다음 달 날짜 표시, useRangeSelect, useTime/minuteStep, getValue/setValue/clear/getControl 과 선택 이벤트를 한 화면에서 확인합니다.

1. 초기값 / 포맷

옵션 조합컨트롤
value: 'now' (오늘)
value: 'day:-7' (7일 전)
value: 'week:2' (2주 후)
value: 'month:-1' (1개월 전)
value: 'year:1' (1년 후)
format: 'YYYY.MM.DD'
placeholder 안내 문구

2. 달력 모양 / 선택 범위

옵션 조합컨트롤
minDate(오늘) ~ maxDate(+30일) 만 선택 가능
defaultDate + setDefaultDate: true (2026-12-25)
numberOfMonths: 2 + showWeekNumber + firstDay: 1(월요일 시작)
이전/다음 달 날짜 숨김 (showDaysInNextAndPreviousMonths: false)
이전/다음 달 날짜 선택 불가 (enableSelectionDaysInNextAndPreviousMonths: false)
헤더 순서 변경 (showMonthAfterYear: false, yearSuffix: ' 년')

3. 시작일 / 종료일 연동 (useRangeSelect) · 날짜+시간 (useTime)

시작일을 고르면 종료일의 선택 범위가 좁혀집니다
날짜 + 시간 (useTime: true, minuteStep: 10)
