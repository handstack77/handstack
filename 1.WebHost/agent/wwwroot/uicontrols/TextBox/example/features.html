TextBox 전체 기능 확인

editType 전체 목록, 입력 마스크, 길이 제한, 숫자 범위, 자동완성(datalist), 검증(validators), getValue/setValue/clear 와 이벤트를 한 화면에서 확인합니다. 값을 입력하고 포커스를 벗어나면(blur) 각 타입의 서식 변환과 형식 검증이 동작합니다.
