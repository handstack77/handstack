Element 전체 기능 확인

전용 컨트롤이 없는 임의의 태그(div/span/td/p/a 등)를 값 컨트롤로 다룹니다. content(innerText 기본/content/html/value), dataType(string/number/bool 과 checkedValue/uncheckedValue), getValue/setValue/clear, click/dblclick 이벤트를 확인합니다. content 를 지정하지 않은 요소에서 clear 는 el.value 만 비우므로 화면 텍스트는 그대로 남습니다.

옵션 조합요소
기본(innerText) - span 클릭 / 더블클릭 해 보세요
content: 'html' - div (HTML 그대로 반영)
굵은 글씨와 기울임
content: 'content' - p (textContent)

textContent 로 읽고 씁니다
dataType: 'number' - td (통화 서식 표시, 읽을 때는 숫자 문자열) 0 원
dataType: 'bool' + checkedValue: 'Y'/uncheckedValue: 'N' true
content: 'value' - output 요소(value 속성 사용) 초기 출력값
