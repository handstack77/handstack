Advanced

chartjs.org 공식 샘플(docs/samples/advanced/*) 7종을 <syn_chartjs>로 재현합니다. register / getChartInstance 처럼 Chart.js 저수준 API를 직접 다루는 예제입니다.

Data Decimation

2,000개 점을 plugins.decimation (lttb 알고리즘)으로 성능 좋게 그립니다.

Derived Axis Type

Chart.LinearScale 를 상속해 값 뒤에 %를 붙이는 커스텀 축을 등록합니다.

Derived Chart Type

Chart.BarController 를 상속해 항상 둥근 모서리인 커스텀 차트 타입( roundedBar )을 등록합니다.

Linear Gradient

scriptable backgroundColor 에서 createLinearGradient 로 그라디언트를 계산합니다.

Programmatic Events

버튼으로 setActiveElements 를 호출해 사용자 조작 없이 포인트를 강조합니다.

Progress Bar

도넛 차트를 진행률 표시줄처럼 구성하고 중앙에 퍼센트를 표시합니다.

Radial Gradient

polarArea 차트에서 createRadialGradient 로 조각별 방사형 그라디언트를 계산합니다.
