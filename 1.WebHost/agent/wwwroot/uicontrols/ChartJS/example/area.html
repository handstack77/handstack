Area Charts

chartjs.org 공식 샘플(docs/samples/area/*) 5종을 <syn_chartjs>로 재현합니다. Area는 별도 차트 타입이 아니라 line 차트의 fill 옵션으로 구현됩니다.

Line Boundaries

fill: 'origin' / 'start' / 'end' / {value:50} 4가지 채움 기준을 비교합니다.

Line Datasets (데이터셋 사이 채움)

fill: '-1' 로 바로 앞 데이터셋과의 사이를 채웁니다.

Line Draw Time

plugins.filler.drawTime 에 따라 채움이 그리드 위/아래 중 어디에 그려지는지 비교합니다.

beforeDatasetsDraw (기본)

beforeDraw (그리드보다 먼저)

Line Stacked (Area)

채워진 라인 여러 개를 stacked: true 로 누적해 영역 차트를 만듭니다.

Radar (채움)

레이더 차트도 fill: true 로 영역을 채울 수 있습니다.
