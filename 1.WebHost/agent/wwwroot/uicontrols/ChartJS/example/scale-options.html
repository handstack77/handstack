Scale Options

chartjs.org 공식 샘플(docs/samples/scale-options/*) 4종을 <syn_chartjs>로 재현합니다.

Center

scales.x/y.position: 'center' 로 축을 데이터 중앙(0)에 배치합니다.

Grid

scales.*.grid 로 격자선 색상·두께·표시 여부를 바꿉니다.

Ticks

ticks.callback 으로 눈금 표시 형식을, ticks.color/padding 으로 스타일을 바꿉니다.

Titles

scales.x/y.title 로 각 축 이름을 표시합니다.
