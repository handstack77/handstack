Scales

chartjs.org 공식 샘플(docs/samples/scales/*) 8종을 <syn_chartjs>로 재현합니다. time 스케일 3종은 ChartJS.js 에 포함된 번들된 moment.js용 자체 제작 date adapter가 있어야 동작합니다.

Linear Min/Max

scales.y.min/max 로 축 범위를 강제로 고정합니다.

Linear Min/Max Suggested

suggestedMin/suggestedMax 는 데이터가 그 범위를 벗어나면 자동으로 확장됩니다.

Linear Step Size

ticks.stepSize 로 눈금 간격을 고정합니다.

Logarithmic

scales.y.type: 'logarithmic' 로 로그 스케일을 사용합니다.

Stacked

막대 차트의 X/Y 축을 모두 stacked: true 로 설정합니다.

Time Line

scales.x.type: 'time' 로 실제 날짜 간격에 비례하는 X축을 그립니다.

Time Combo

표본 간격이 다른 두 시계열 데이터셋을 같은 시간축에 겹쳐 그립니다.

Time Max Span

데이터는 더 넓은 기간을 갖지만 time.min/max 로 표시 구간만 제한합니다.
