Tooltip

chartjs.org 공식 샘플(docs/samples/tooltip/*) 5종을 <syn_chartjs>로 재현합니다.

Content

callbacks.title/label/footer 로 툴팁 내용을 직접 구성합니다.

HTML Tooltip

기본 캔버스 툴팁 대신 external 콜백으로 HTML 툴팁을 그립니다.

Interactions

interaction.mode 4가지(index/nearest/point/dataset)를 비교합니다.

index

nearest

point

dataset

Point Style

tooltip.usePointStyle: true 로 툴팁 마커를 포인트 모양과 맞춥니다.

Position

기본 'average' 위치 지정과 커스텀 등록 위치 지정( Tooltip.positioners.topLeft )을 비교합니다.

average(기본)

topLeft(커스텀)
