FileClient 전체 기능 확인

저장소 유형별(단일/프로필/다중/에디터 이미지) 업로드 컨트롤, getFileSetting/uploadUI, 업로드 결과 콜백(fileUpdateCallback), 파일 정보 조회/삭제(getItem/getItems/deleteItem/deleteItems), updateDependencyID/updateFileName, 팝업 없는 업로드(uploadDataUri/uploadBlob), 다운로드(fileDownload), 유틸(getTemporaryDependencyID/toFileLengthString)을 확인합니다.

업로드/조회/삭제/다운로드는 repository 모듈(기본 /repository/api/storage)이 실행 중이고 샘플 저장소 TSTLS01(단일), TSTLP01(프로필), TSTLM01(다중), TSTLE01(에디터 이미지)가 등록된 환경에서 동작합니다. 서버가 없으면 저장소 조회 경고가 표시되며, 서버가 필요 없는 유틸 메서드는 그대로 확인할 수 있습니다.

TSTLM01 다중 첨부파일 (3개, 10MB)
TSTLE01 에디터 내 이미지 (이미지 30개, 20MB)
